# resources/kafka/qa

Place the following files here (all are gitignored):

| File | Description |
|------|-------------|
| `your-service-account.keytab` | Kerberos keytab for the QA service account |
| `krb5.conf` | KDC configuration provided by the Kafka cluster team |
| `common.pem` | SSL CA certificate for the QA Kafka cluster |
